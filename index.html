Перевантаження операторів у C++

1. Головна суть

  • Що це? Можливість перевизначити дію стандартних операторів (+, -, ==, <<) для об'єктів власних класів.
  • Навіщо? Щоб код був читабельним. Замість vec1.add(vec2) ми пишемо просто vec1 + vec2.
  • Синтаксис: Використовується ключове слово operator, після якого йде символ оператора.

2. Що не можна перевантажити?

  • :: (Доступ до області видимості)
  • . (Доступ до члена класу)
  • .* (Доступ до члена за вказівником)
  • ?: (Тернарний оператор)
  • sizeof, typeid, static_cast тощо.

3. Метод класу VS Дружня функція (friend)

  • Як метод класу: Лівий операнд завжди є об'єктом цього ж класу (неявно передається через this). Зручно для операторів +=, -=.
  • Як дружня функція: Використовується, коли лівий операнд має інший тип (наприклад, потік ostream для <<). Має доступ до private полів.

4. Швидкий приклад для захисту

class Point {
private:
    int x, y;
public:
    Point(int x, int y) : x(x), y(y) {}

    // Перевантаження як метод класу
    Point operator+(const Point& other) {
        return Point(this->x + other.x, this->y + other.y);
    }

    // Перевантаження як дружня функція (для виводу в консоль)
    friend std::ostream& operator<<(std::ostream& os, const Point& p) {
        os << "(" << p.x << ", " << p.y << ")";
        return os;
    }
};
